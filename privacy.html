Privacy Policy

CodeToVideo Auto Reply · Last updated: October 23, 2026

1. What this app does

CodeToVideo Auto Reply is a free Instagram automation built by an independent creator for her own Instagram account (@codetovideo). When someone comments a keyword (e.g. LINK) on her posts, the app posts a public auto-reply to that comment and sends the commenter a Direct Message containing a link she chose (her LinkHub page). The app never posts on anyone else's behalf, never comments on other accounts' posts, and never sends unsolicited messages.

2. What data we collect

Through Meta's official Instagram webhooks and Graph API, the app receives only what is needed to do its job:

  • Comment text on her own posts, plus the commenter's Instagram username and user ID — used to detect the keyword and send the auto-reply.
  • Message content in direct-message conversations the app is part of — used to answer basic questions.
  • No other personal data. We do not collect email addresses, phone numbers, locations, photos, or anything outside Instagram comments/messages on this one account.

3. How the data is used

  • To post the keyword auto-reply and deliver the requested link by DM.
  • To remember which comments were already answered (a simple "seen" record), so no one gets duplicate replies.
  • Nothing else. Data is never sold, rented, or shared with advertisers or third parties.

4. Where data is stored and for how long

Data lives on the creator's own private server (Oracle Cloud free tier, EU/Frankfurt region). Comment "seen" records are kept for 90 days to prevent duplicate replies, then deleted. API tokens are stored server-side and never shared or logged publicly.

5. Data deletion

If you want any data the app holds about you deleted, message @codetovideo on Instagram with the word DELETE and we will remove your records within 7 days. (Meta's official user data-deletion request flow is also supported once the app is published.)

6. Security

The webhook endpoint verifies every request with Meta's app-secret signature; requests with an invalid signature are rejected. The server is kept up to date and access is restricted to the developer.

7. Contact

Questions about this policy: reach out via Instagram DM to @codetovideo.

8. Changes

If this policy changes, the new version will be posted at this same address with a new "Last updated" date.
